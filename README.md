# Portfolio Wanny YEMBELE — BUT Réseaux & Télécommunications (IUT de Béthune)

## 📋 Présentation du projet

Ce dépôt héberge mon portfolio personnel en ligne, développé dans le cadre de mon BUT **Réseaux & Télécommunications** à l'IUT de Béthune (1re année validée, actuellement en 2e année — rentrée septembre 2026).

Le site présente mon parcours académique, mes compétences techniques (administration systèmes, réseaux, sécurité, développement) ainsi que les comptes rendus de mes SAE et TP. Il intègre une fonctionnalité multilingue (Français/Anglais).

🔗 **Site en ligne :** [jack-ux52.github.io/WannyYEMBELE](https://jack-ux52.github.io/WannyYEMBELE)
🟢 **En recherche d'alternance de 2 ans (rentrée septembre 2026)** dans le domaine des réseaux et télécommunications.

## 🛠️ Technologies et bibliothèques utilisées (site web)

- **Langages** : HTML5, CSS3, JavaScript.
- **Framework CSS** : [Bootstrap 5.3.8](https://getbootstrap.com/).
- **Bibliothèques JS** :
  * *AOS* (Animate On Scroll) pour les animations.
  * *Isotope Layout* pour le filtrage de la galerie portfolio.
  * *GLightbox* pour l'affichage des images en mode "lightbox".
  * *Swiper* pour les carrousels tactiles.
- **Icônes** : Bootstrap Icons.

## 🎓 Compétences techniques illustrées dans les comptes rendus

Les SAE et TP hébergés dans ce dépôt couvrent :

- **Systèmes & serveurs** : Windows Server / Active Directory, Linux (Debian, Ubuntu), virtualisation.
- **Réseaux** : TCP/IP, VLAN, routage, Cisco IOS, Wireshark.
- **Téléphonie d'entreprise (ToIP)** : Asterisk, téléphones SIP Cisco et Fanvil.
- **Conteneurisation** : Docker & Docker Compose (WordPress + MySQL + Portainer).
- **Bases de données** : PostgreSQL.
- **Sécurité** : sensibilisation cybersécurité (certification ANSSI SecNumAcadémie).

## 🚀 Fonctionnalités du site

- **Design responsive** : adapté à tous les écrans (mobile, tablette, desktop) grâce à Bootstrap.
- **Navigation intuitive** : menu "One Page" avec défilement fluide (Accueil, À propos, Portfolio, CV, Projets).
- **Filtrage dynamique** : section Projets triable par catégorie de compétence — **Administrer**, **Connecter**, **Programmer**.
- **Animations** : bibliothèque AOS pour l'apparition des éléments au scroll.
- **Support multilingue** : structure prête pour l'internationalisation (fichiers `.html` / `.anglais.html`).
